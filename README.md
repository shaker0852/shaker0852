# مرحباً، أنا شاكر 👋

أعمل في مجال التحول الرقمي وتطوير المنصات والأنظمة التشغيلية.

## اهتماماتي التقنية
- تحليل البيانات وبناء أدوات تدعم اتخاذ القرار
- الذكاء الاصطناعي وتطبيقاته في الخدمات التشغيلية
- تصميم تجربة المستخدم وخدمة العملاء الرقمية
- أتمتة سير العمل

## أدوات أستخدمها
- **n8n**: أتمتة سير العمل بين الأنظمة
- **Miro**: تخطيط الأفكار ورسم العمليات
- **Google Workspace**: التعاون على الوثائق والجداول والعروض
- **GitHub**: إدارة الشيفرة ونشر المشاريع

### Claude: أفضل 5 أدوات
1. **Claude Code**: تطوير الأدوات والمشاريع من الطرفية
2. **Skills**: إعادة استخدام سير العمل المتكرر بأمر واحد
3. **Artifacts**: إنشاء صفحات ولوحات تفاعلية قابلة للمشاركة
4. **Connectors**: ربط Claude بالتطبيقات والبيانات الخاصة بك
5. **Projects**: تنظيم المحادثات والملفات حول موضوع واحد
